# AI Harness

Skill as a Service（SAAS, project-specific term）

## Goal

提供一个 jar 包，帮助用户快速实现 AI Agent 访问能力。
Provide a jar package to quickly enable AI Agent access capabilities for users.

## Features

### API to Skill

扫描所有 Controller ，并将每一个接口转换为 AI Agent 可以直接调用的 Skill。
Scan all controllers and convert each API endpoint into a skill that AI agents can invoke directly.

### Project capability analysis

扫描项目代码，分析其能力，并自动生成项目使用说明，方便 AI Agent 理解与接入。
Scan project code, analyze capabilities, and generate usage instructions so AI agents can understand and integrate quickly.
